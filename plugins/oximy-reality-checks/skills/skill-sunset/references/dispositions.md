# Dispositions

Choose exactly one primary disposition.

- `keep`: the current contract and implementation are supported by representative evidence.
- `narrow-trigger`: false activations or context load dominate, while execution is useful when correctly invoked.
- `revise`: the capability remains useful, but instructions, references, scripts, outputs, or completion gates are defective.
- `merge`: another skill owns substantially the same trigger and workflow; preserve one source of truth.
- `quarantine`: risk or uncertainty is too high for automatic invocation, but evidence is insufficient for retirement.
- `retire`: the skill is redundant, harmful, obsolete, or unsupported by the required workflows.
- `insufficient-evidence`: the current sample cannot support a lifecycle decision.

Popularity, author reputation, and security scan status can inform trust, but none establish local effectiveness.
