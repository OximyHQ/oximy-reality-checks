# Change classification

Assign one primary category and optional secondary tags. Quote or point to the changed region.

| Category | Test |
|---|---|
| Correctness | Would the earlier artifact produce a materially wrong result? |
| Omission | Was required information, behavior, or a case absent? |
| Unsupported claim | Did the draft state more than the evidence supports? |
| Task misunderstanding | Did it solve a different problem or ignore an explicit constraint? |
| Judgment | Did a human supply a decision that could not be recovered mechanically? |
| Structure | Did the artifact require reorganization to become usable? |
| Style | Were both versions substantively acceptable, with a preference changed? |
| Policy or risk | Was material changed to meet legal, security, privacy, or organizational policy? |
| Formatting | Did presentation change without changing meaning? |
| Changed scope | Was the requirement introduced only after the AI version? |

Do not count changed scope as an AI failure. Do not call a stylistic preference a correctness repair. For code, passing tests establish only the behavior the tests cover. For prose, an accepted final document establishes acceptance, not factual truth.
