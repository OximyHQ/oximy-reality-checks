# Privacy model

The bundled scripts operate locally and make no network requests. They minimize report content by default, hash source artifacts for identity, and avoid printing full memory content or local paths where a stable token is sufficient.

Installing a skill does not change the privacy behavior of the host agent or AI service. Before supplying sensitive material, review the destination service, account controls, contractual terms, retention settings and the exact task. If these facts are unavailable, treat them as unknown.

The skills distinguish collection, transmission, storage, retrieval and reporting. Evidence of one does not establish the others.
