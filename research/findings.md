# What the corpus changed

The 400-file structural sample had a median of 990 words, 166 lines, 15 headings and eight numbered steps. Ninety-one percent used frontmatter and eighty-six percent contained a workflow. Those conventions are useful for discovery and execution, but they do not separate a dependable skill from a polished prompt.

The rarer properties became this collection's release bar:

| Structural signal | Sample prevalence | Decision for this collection |
|---|---:|---|
| Explicit completion criterion | 4.0% | Required in every skill |
| Explicit authorization language | 2.8% | Required wherever an action could alter external state |
| Explicit unknown state | 13.8% | Unknown must remain a valid outcome |
| When-not-to-use guidance | 18.8% | Every description or boundary must name a non-goal |
| Safety boundary | 36.0% | Every skill gets a scope and interpretation boundary |
| Bundled scripts | 36.5% | Add one only where deterministic work prevents improvisation |
| Required output | 43.5% | Every skill specifies a reviewable deliverable |
| Progressive disclosure | 43.8% | Put taxonomies and adapters in references, not the main workflow |

Manual review added four writing principles the feature counts cannot capture:

1. A trigger is a routing contract, not marketing copy.
2. The workflow should force the hardest decision instead of offering generic advice.
3. Mechanical helpers should narrow uncertainty and announce their limits.
4. A skill should stop with an honest evidence gap rather than manufacture closure.

These findings shaped the authoring standard; they are not claims that the resulting skills are behaviorally superior. Behavioral evaluation remains a separate release gate.
