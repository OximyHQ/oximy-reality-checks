# Security

## Report a concern

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing secrets, customer data, exploit details or sensitive traces.

## Scope

The repository contains instructions and standard-library Python helpers. The helpers do not make network requests and are designed to avoid modifying source inputs. They are aids, not guarantees: regex detection is incomplete, trace evidence can be partial, and a valid schema does not prove a truthful report.

Repository owners will acknowledge a private report, assess affected versions, and coordinate remediation and disclosure through that report. No response-time guarantee is currently offered.
