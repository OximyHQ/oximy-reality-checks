# Security

## Report a concern

During private preview, report security concerns privately to the repository owners. Do not open a public issue containing secrets, customer data, exploit details or sensitive traces.

## Scope

The repository contains instructions and standard-library Python helpers. The helpers do not make network requests and are designed to avoid modifying source inputs. They are aids, not guarantees: regex detection is incomplete, trace evidence can be partial, and a valid schema does not prove a truthful report.

Before a public release, the project needs a confirmed security contact and disclosure channel.
